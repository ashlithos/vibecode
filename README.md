# vibecode

Ashley's playground repo for vibe-coded experiments.

Skills don't live here: they're all in [ashlithos/UX-skills](https://github.com/ashlithos/UX-skills),
installable as Claude Code plugins:

```
/plugin marketplace add ashlithos/UX-skills
/plugin install clean-site@ux-skills
/plugin install product-video@ux-skills
```

## Experiments

- [`growth-pattern-atlas/`](growth-pattern-atlas/index.html): a field guide for growth UX in AI agent and data tools. A Surface Picker sets a loudness ceiling (urgency × relevance); the Atlas shows 25 patterns placed in a mock agent workspace, with timing, do's and don'ts, and metrics.
