# 03 Shape Morph: audio notes

**Sound world:** rhythmic plucky arpeggio (future-bass pluck), glassy pad, one pitched morph-whoosh per shape change.

| | |
|---|---|
| Tempo / key | 120 BPM, D major: D, Bm7, Gmaj7, A(sus), one chord per morph stage |
| Instruments | 16th-note up/down pluck arpeggio (filter opening across the chain, then cut at 3.4 s for the motif) · glass pad · sub bass on each chord change |
| Sonic logo | bright pluck + FM bell: D4 → A4 → E5 at 3.50 / 3.75 / 4.00 s, landing as the D, the second a, and the X fold into place |
| The accent | **4.00 s**: the X lands with its squash. A pluck chord Dadd9 (D3-A3-E4-F#4-A4), glass pad, 808 sub D2 and a rising morph sweep on E5 |
| SFX (only what you see) | bubble pop on the split · pitched morph sweep as the dots settle into the cloud · a rising triangle blip per bar snapping in (F#5…F#6) · downward morph as the segments merge · swish + soft click as the bars swing into rows · pitched morph sweeps on the letters that land off the motif |
| Tail | pad + bell ring; silent at 6.8 s |

**What I'd change with more time:** sidechain-free but more groove in the arp (accent pattern tied to each morph's ease); tune the morph sweeps to start on the previous chord tone so every transition sounds like a glide between chords.
